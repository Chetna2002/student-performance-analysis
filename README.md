# Student Performance Analysis (EDA & Insights)

An end-to-end exploratory data analysis and student risk segmentation project analyzing 1,000 student exam records across Mathematics, Reading, and Writing.

## Project Overview
This project evaluates socioeconomic and academic drivers of exam outcomes to provide actionable, data-backed policy recommendations for school leadership.

## Key Insights
* **Test Preparation:** Completing prep courses reduces at-risk rates from 18.5% down to 7.3%.
* **Socioeconomic Gaps:** Students on subsidized lunch plans exhibit a 24.2% failure rate vs. 9.1% on standard lunch.
* **Subject Correlations:** Reading and writing scores correlate strongly ($r = 0.95$), and literacy directly predicts math achievement ($r = 0.82$).
* **Gender Nuances:** Female students excel in reading (+7.1) and writing (+9.2), while male students outperform in math (+5.0).

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Google Colab / Jupyter Notebook

## Recommendations for Leadership
1. Make standardized test preparation a mandatory, in-class module.
2. Provide subsidized after-school literacy and math clinics for free/reduced lunch students.
3. Incorporate word-problem translation frameworks directly into math curricula.

## Most Impactful Recommendation
Making the test preparation course mandatory delivers the highest immediate ROI. Completing the course cuts student failure risk from 18.5% down to 7.3%. Because this intervention is fully managed through administrative scheduling and curriculum design rather than household economics, the school can implement it immediately with guaranteed measurable gains.
